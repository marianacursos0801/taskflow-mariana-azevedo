# M&J Tur — Portal universitário

Aplicação responsiva de demonstração baseada nas telas e na especificação do ZIP.

## Como abrir

Abra index.html em um navegador moderno. Não é necessário instalar dependências nem iniciar servidor.

## Funcionalidades

- Acesso demonstrativo com perfil de aluno, motorista e operação.
- Cadastro de aluno com validação de CPF, e-mail único, endereço, contato, rota e dias recorrentes.
- Cadastro de motorista com código de autorização demonstrativo.
- Presença semanal, consulta de rota, lista de passageiros, atualização de previsão e avisos.
- Edição de dados do aluno, horários e comunicados.
- Persistência local no navegador.

## Contas de demonstração

- Aluno: aluno.demo@mjtur.com.br / mjtur2026
- Motorista: motorista@mjtur.com.br / mjtur2026
- Operação: gestao@mjtur.com.br / mjtur2026
- Código de cadastro de motorista: MJ-TUR-2026

Os dados são fictícios e permanecem no navegador atual. A autenticação local não protege dados reais; não use informações pessoais reais. Não há sincronização entre dispositivos, servidor, mapas ou APIs externas. A sequência de paradas é uma demonstração simplificada.
